## 1. 背景与定位

股票详情是 portfolio 的「个股深度研判综合容器」（Master §3.4），借鉴**富途牛牛顶部 Tab + 同花顺固定底栏**。用户从自选列表 / 全局搜索下钻进来，在顶部 Tab 间切换不同研判维度，底部常驻动作底栏收拢高频操作。

本页是**只读消费容器**：行情 / 估值 / 财务数据来自 03 设计的 capability-port，加/删自选 / 预警 / 笔记 / 研报均为跨特性入口（逻辑属各自 PRD）。本页几乎不新增持久化实体（见 §5）。

---

## 2. 两阶段交付边界（本特性核心约束）

理杏仁**仅提供 EOD 日频数据，无任何实时 / 盘中 / 分钟 / tick / 盘口 / 资金流**（03 §4-§5 锁定）。故本特性拆两阶段，**阶段一先打通理杏仁现有数据并预留扩展点，阶段二接入实时源后透明补充**：

| 阶段       | 数据来源                          | 落地内容                                                                           | 扩展机制                                                                                 |
| ---------- | --------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **阶段一** | 理杏仁 EOD（fundamental/fs/日线） | 报价 header（EOD 可算字段）+ 图表（日 K 及以上）+ 公司（财务/估值/分位）+ 分析入口 | 消费 03 `QuotePort`（EodBacked 实现）/ `EodBarPort`；前端为盘中字段/分时图**预留渲染位** |
| **阶段二** | 实时行情 provider（03 §9 候选）   | 报价 header 恢复盘中字段；图表新增分时图 / 逐笔成交明细                            | `QuotePort` 换 `RealtimeQuoteAdapter`，**消费者零改动**（03 §7.3 已留缝）                |

> 阶段一**不是简化版**——是数据源决定的真实边界。盘中字段在阶段一**不展示**（而非占位空壳），实时源就位后由端口透明恢复。阶段二的触发独立于本 PRD（待第二 provider 选型，03 §9）。

## 3. 页面结构与交互

整体框架（**富途式：固定顶 + 滚动中 + 固定底**）：

1. **固定顶栏**（不随内容滚动）：nav 行（标的名 / 代码 / market；切「公司/分析」Tab 或图表滚过报价时，nav 内联 condensed 现价 + 涨跌）+ **内容 Tab 行（图表/分析/公司，紧贴 nav 下方）**。
2. **滚动内容区**（随 Tab 切换）：图表 Tab[报价 block → K 线]、公司 Tab[财务估值]、分析 Tab[研报空态]。
3. **固定底栏**（不随内容滚动，同花顺式，4 项）。

> 报价是**图表 Tab 的内容、非跨 Tab 常驻 header**（富途范式）——切「公司/分析」由 nav 内联 condensed 现价。

### 3.1 顶部 Tab 栏（富途 7 Tab → V1 保留 3 个）

原富途 Tab：`图表 ｜ 期权 ｜ 轮证 ｜ 评论 ｜ 资讯 ｜ 分析 ｜ 公司`。V1 取舍：

| 原 Tab | V1 处置                                   |
| ------ | ----------------------------------------- |
| 图表   | ✅ 保留（K 线，默认落点）                 |
| 期权   | 🚀 V2（衍生品闭环，Master §1 V2）         |
| 轮证   | ❌ V1 不做（港股衍生品，归属工具无意义）  |
| 评论   | ❌ V1 不做（社交，非核心）                |
| 资讯   | ❌ V1 不做（理杏仁无资讯源）              |
| 分析   | ✅ 保留 → **改作「研报」容器**（见 §3.5） |
| 公司   | ✅ 保留 → 理杏仁财务/估值/基本面（§3.6）  |

**V1 顶部 = `图表 ｜ 分析 ｜ 公司` 三 Tab。**

### 3.2 报价 block（图表 Tab 内容首屏，非跨 Tab 常驻）

报价是**图表 Tab 的内容**（随图表 Tab 滚动），切「公司/分析」Tab 时由 nav 内联 condensed 现价替代（富途范式）。展示标的身份 + 核心价量估值。**阶段一仅展示 EOD 可算字段**：

| 阶段一展示（EOD 可算）                                              | 阶段二补充（实时源）                          |
| ------------------------------------------------------------------- | --------------------------------------------- |
| 名称 + 代码 + market；最新价（=最近 EOD 收盘）/ 涨跌额 / 涨跌幅     | 最高 / 最低 / 今开 / 盘中成交额·成交量        |
| 昨收（前一 EOD 收盘）；市盈率 TTM / PB / 股息率 / 总市值 / 流通市值 | 量比 / 委比 / 内外盘 / 振幅 / 均价 / 盘前盘后 |

- 涨跌数值**涨红跌绿**（复用 03 §7.1 新增 `quote.up/down/flat` token，不复用 err/ok）。
- 港股特有字段（ADR 换算价 / 美股盘后 / 人民币柜台 / 期货 / 低水）：A 股无此概念，且港美股理杏仁覆盖薄（03 §10）——**V1 不做**。
- 阶段一前端为盘中字段**预留布局位**，实时源就位后填充，不重排。
- **condensed 现价**：切「公司/分析」Tab 或图表 Tab 滚过报价时，nav 行内联 名称 + 现价 + 涨跌（小字，涨红跌绿）。

### 3.3 图表 Tab（K 线）

| 元素                                   | 阶段一                             | 阶段二      |
| -------------------------------------- | ---------------------------------- | ----------- |
| 周期：日 K / 周 K / 月 K / 季 K / 年 K | ✅ 由理杏仁 EOD 日线聚合           | —           |
| 复权切换：不复权 / 前复权 / 后复权     | ✅ 03 `EodBarPort` adjust 参数支持 | —           |
| 成交量副图（日频）                     | ✅ 日线 volume                     | —           |
| 1D 分时 / 5 日分时                     | ❌ 无分时源                        | ✅ 实时源补 |
| 右侧逐笔成交明细（tick）               | ❌ 无 tick 源                      | ✅ 实时源补 |

- 涨跌配色同 §3.2。K 线图表库选型与 mockup 互锁（见 §9）。

### 3.4 公司 Tab（理杏仁数据，V1 支撑最好）

理杏仁 fundamental + fs + cvpos 分位为本 Tab 主力数据源（03 §5），V1 全量可落：

1. **估值**：PE（TTM/静/动）/ PB / PS / 股息率 / 总市值 / 流通市值 / 总股本（`FundamentalPort`）。
2. **估值分位**：PE / PB 历史百分位（3 年 / 5 年，理杏仁 cvpos 招牌能力）。
3. **财务衍生**：ROE / 毛利率 / EPS（TTM）/ BPS（`FinancialsPort`，财报季更新）。
4. **静态身份**：名称 / 代码 / market / 证券类型 / 币种 / 52 周高低（`Instrument`）。
5. **公司行动**（可选）：分红 / 拆股历史（`CorporateActionPort`）——V1 可只读展示。

### 3.5 分析 Tab（研报容器，完整能力属独立 PRD）

- 本 PRD **仅承载「研报」入口 / 容器**：分析 Tab 下展示该标的研报列表占位 + 进入研报阅读的入口。
- **完整研报能力**（PDF 接口拉取 / 手动导入 / 原生·WebView 阅读器 / 双指缩放 / 翻页 / 版本化）拆为**独立研报 PRD**（后续，Master §3.8）——依赖文件存储 / 导入基础设施，独立成篇。
- 本特性 spec / impl **不实现研报内核**，只留 Tab 壳 + 入口契约。

### 3.6 固定动作底栏（同花顺式，新建，4 项）

去掉富途的「交易 / 期权」按钮行 + app 级底部 nav（自选/市场/账户/资讯/发现/搜索），新建详情页常驻底栏：

| #   | 操作       | 说明                                                                                      |
| --- | ---------- | ----------------------------------------------------------------------------------------- |
| 1   | 预警       | 进预警配置（→ §3.5 预警 PRD）；本页只出入口                                               |
| 2   | 笔记       | 写笔记（→ §3.6 笔记 PRD）；本页只出入口                                                   |
| 3   | 加/删自选  | **状态切换**：不在自选 → 「加自选」（默认落「自选」组，PRD04 FR8）；已在自选 → 「删自选」 |
| 4   | ⋯ 更多工具 | overflow 菜单：**调分组·颜色标记**（PRD04 §3.2「分组·颜色」）+ **分享**；后续再加新能力   |

- 底栏与 PRD04 长按菜单是**同一组操作的不同入口**（PRD04 §3.2 已声明详情底栏同展现这组操作）。
- 「加/删自选」需读当前标的的自选状态（PRD04 `WatchlistItem`）实时切换文案。

## 5. 数据模型（PRD 级，非最终 schema）

本页为**只读消费容器**，数据全部来自 03 设计的 portfolio schema + capability-port，**不新增本页专属持久化实体**：

| 数据                         | 来源                                                      |
| ---------------------------- | --------------------------------------------------------- |
| 标的身份 / 52 周高低         | 03 `Instrument`（market+code 业务主键，对齐 Master §4.1） |
| 最新价（EOD）/ 涨跌 / 日 K   | 03 `QuotePort`（EodBacked）/ `EodBarPort` → `DailyBar`    |
| PE/PB/PS/股息率/市值/分位    | 03 `FundamentalPort` → `FundamentalSnapshot`              |
| ROE/毛利率/EPS/BPS           | 03 `FinancialsPort` → `FinancialMetric`                   |
| 分红 / 拆股（可选展示）      | 03 `CorporateActionPort` → `CorporateAction`              |
| 自选状态（加/删/调分组切换） | PRD04 `WatchlistItem`（按 market+code 查归属）            |
| 研报                         | 独立研报 PRD（本页不建模）                                |

- **边界澄清**：报价快照（最新/涨跌/盘中字段）属内存实时计算 / Redis 热缓存（03 §8），不落本页表。
- 分享 / 切股上下文等为无状态交互，不建模。

## 6. 关键产品决策

| 决策点              | 结论                                                      | 理由                                                          |
| ------------------- | --------------------------------------------------------- | ------------------------------------------------------------- |
| 顶部 Tab 取舍       | V1 = 图表 / 分析 / 公司；期权 V2；轮证·评论·资讯 砍       | 归属工具非交易终端；衍生品/社交非核心；资讯理杏仁无源         |
| 数据交付节奏        | **两阶段**：阶段一理杏仁 EOD + 预留扩展，阶段二实时源补充 | 理杏仁无实时；先打通现有数据，端口预留实时透明升级（03 §7.3） |
| 报价字段阶段一范围  | 仅 EOD 可算字段；盘中字段隐藏、不占位空壳                 | 盘中无源；占位空壳误导用户。实时源就位由端口恢复              |
| 图表阶段一范围      | 日 K 及以上 + 复权切换 + 成交量副图；无分时 / 逐笔        | 理杏仁仅 EOD 日线，分时/tick 无源                             |
| 分析 Tab = 研报容器 | 本页只承载入口；完整研报能力独立 PRD                      | 研报依赖文件存储/导入基础设施，体量够独立成篇，做成完善能力   |
| 底栏 4 项           | 预警 / 笔记 / 加·删自选 / ⋯更多工具                       | 同花顺式常驻底栏；对齐 Master §3.4 并把「调分组」下沉更多工具 |
| 更多工具内容        | 调分组·颜色标记 + 分享                                    | V1 先放这两个，后续规划新能力                                 |
| 加自选默认组        | 默认落「自选」组；调分组/打色走更多工具                   | 对齐 PRD04 FR8；快速加 + 精细调分离                           |
| 涨跌配色            | 涨红跌绿（复用 03 `quote.*` token）                       | A 股惯例 + 模块视觉统一，不复用 err/ok（语义相反）            |
| 港股特有字段        | ADR/盘后/人民币柜台/期货/低水 V1 不做                     | A 股为主，港美股理杏仁覆盖薄（03 §10）                        |
| 明暗主题            | 一律项目浅色 theme                                        | 全模块视觉统一；富途截图仅布局参照，不照搬深色                |

## 7. 样式规范

1. **follow 项目 theme tokens**（`apps/mobile/src/theme/`）；涨跌专用 `quote.up/down/flat`（03 §7.1）。富途截图仅作**布局参照**，配色 / 明暗按项目浅色 theme，不照搬。
2. 项目现有 UI 组件（`apps/mobile/src/ui/`）**无 Tab 栏 / K 线图表 / 固定底栏 / overflow 菜单**组件——SDD 阶段需新建。
3. **K 线图表为数据可视化**：图表库选型与 mockup 互锁（见 §9），不在 PRD 锁死。
4. 阶段一前端组件需为阶段二盘中字段 / 分时图**预留渲染位**（FR11），避免阶段二重排。

## 8. 边界与非功能 + 剩余延后

### Out of Scope（V1 本特性不做）

1. **实时 / 盘中行情**（阶段二，待实时源）——盘中报价字段 / 分时图 / 逐笔成交。
2. **期权 / 轮证 Tab**——期权 V2，轮证不做。
3. **评论 / 资讯 Tab**——社交不做；资讯理杏仁无源。
4. **研报完整能力**——独立研报 PRD（拉取/导入/阅读器/版本化），本页仅入口。
5. **预警 / 笔记逻辑**——各自 PRD，本页只出入口。
6. **港美股深度字段**——A 股为主。

### NFR

1. 详情页为高频只读容器，行情 / 估值读 03 Redis 热快照（TTL 至下次 EOD），渲染流畅；K 线大数据量需虚拟化 / 抽样。
2. **阶段一预留扩展点**：阶段二实时 adapter 接入须**零前端业务改动**（消费端只依赖 03 `QuotePort`/`EodBarPort` 接口，vendor 在 module 工厂切换）。

### 剩余延后（待 mockup / SDD）

1. **K 线图表库选型**（与 mockup 互锁）：RN 候选 react-native-skia / victory-native / wagmi-charts 等，SDD 决。
2. **复权默认方式**（前复权 / 后复权 / 不复权）→ mockup / SDD。
3. **分享形态**（截图分享 / 链接分享）→ mockup / SDD。
