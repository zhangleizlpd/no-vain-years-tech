## 1. 背景与定位

证券市场设置页是 portfolio 模块的**市场准入开关中枢**。它决定哪些证券市场在当前用户下被"激活"，激活态是全局 API 消费与流量分配的准入门：

- **激活市场** → 全局模糊搜索、资产导入、行情轮询、EOD 同步等下游能力对该市场端点开放。
- **未激活 / 置灰市场** → 底层不执行任何节点初始化；全局搜索 / 导入 / 行情轮询彻底熔断对该市场端点的调用（per Master §3.1）。

本页只负责**用户市场偏好的开关与持久化**；市场端点的真实初始化 / 熔断机制属网关层实现，跨页，不在本 PRD 锁定。

---

## 2. 用户故事（User Scenarios）

1. 长期 A 股价值投资者首次进入：看到 A 股（CNY）默认已激活，港股 / 美股默认关闭，海外市场置灰。
2. 用户想纳入港股资产：打开「港股（HKD）」开关 → 下游搜索 / 导入 / 行情对港股端点放开。
3. 纯美股用户：打开「美股（USD）」、关闭「A 股（CNY）」，只保留美股。
4. 用户尝试关掉**最后一个**激活市场：系统阻止，开关弹回原位并轻提示「至少保留一个激活市场」。
5. 用户看到日股等海外市场置灰不可点：明确知道未来（V2+）会支持，当前不可用。

---

## 3. 页面结构与交互

### 3.1 布局

1. **顶部标题**：「证券市场」。区别于图一来源 app 的顶部行——**不带右侧"当前市场 + 下拉箭头"**（本页是多市场开关页，不是单市场选择器）。
2. **主体**：单层**平铺**市场列表（非弹层 / 非下拉），按下表固定顺序，分「核心」「海外」两组。
3. **每行结构**：左侧 label = `市场名（ISO 货币码）`；右侧 toggle 开关（图二行布局：label 左 + 开关右）。

### 3.2 市场清单（顺序固定）

| 分组 | label           | ISO 4217 | V1 默认态 | 开关可交互  |
| ---- | --------------- | -------- | --------- | ----------- |
| 核心 | A 股（CNY）     | CNY      | **ON**    | ✅ 可开关   |
| 核心 | 港股（HKD）     | HKD      | OFF       | ✅ 可开关   |
| 核心 | 美股（USD）     | USD      | OFF       | ✅ 可开关   |
| 海外 | 日股（JPY）     | JPY      | —         | ⛔ 置灰禁用 |
| 海外 | 新加坡（SGD）   | SGD      | —         | ⛔ 置灰禁用 |
| 海外 | 马来西亚（MYR） | MYR      | —         | ⛔ 置灰禁用 |
| 海外 | 加拿大（CAD）   | CAD      | —         | ⛔ 置灰禁用 |
| 海外 | 澳大利亚（AUD） | AUD      | —         | ⛔ 置灰禁用 |
| 海外 | 韩股（KRW）     | KRW      | —         | ⛔ 置灰禁用 |

> A 股含北交所（沪 / 深 / 北三市），范围大于"沪深"——per Master §3.1。

### 3.3 交互规则

1. 点击核心市场 toggle → 切换激活态，**即时持久化**到用户市场偏好（无独立"保存"按钮，已定即时，见 §8 决策）。
2. **最少激活约束（min-1）**：核心市场激活数 ≥ 1。尝试关掉最后一个激活市场时——开关不生效、视觉弹回、轻提示「至少保留一个激活市场」。
3. **海外市场**：toggle 恒为禁用置灰态，点击无任何副作用；行内副文案固定为「即将支持」。

## 4. 功能需求（Functional Requirements）

| #   | 需求                                                                                                                               |
| --- | ---------------------------------------------------------------------------------------------------------------------------------- |
| FR1 | 页面展示全部 9 个市场，分核心 / 海外两组，顺序固定（§3.2）。                                                                       |
| FR2 | 核心市场（A 股 / 港股 / 美股）toggle 可切换，状态持久化到用户级市场偏好。                                                          |
| FR3 | 海外市场（日 / 新 / 马 / 加 / 澳 / 韩）toggle 恒为禁用置灰态，V1 不可激活。                                                        |
| FR4 | min-1 约束：核心市场激活数始终 ≥ 1；阻止关掉最后一个激活市场。                                                                     |
| FR5 | 每个市场 label 追加 ISO 4217 货币码（格式 `市场名（XXX）`）。                                                                      |
| FR6 | 首次默认态：A 股 ON，港股 / 美股 OFF。                                                                                             |
| FR7 | 激活态变更需可被下游消费（全局搜索 / 导入 / 行情轮询的市场端点准入）；传播机制（事件 vs 偏好表读取）属网关层，本页只保证状态可读。 |
| FR8 | ISO 货币码作为后续多币种折算（Master §3.3 外币统一折算 RMB）的市场→币种映射来源。                                                  |

## 5. 数据模型（PRD 级，非最终 schema）

1. **用户市场偏好**（per user）：`{ market: 枚举, active: bool }`——记录核心市场激活态。
2. **市场字典**（系统静态）：`{ marketCode, 显示名, isoCurrency, group: core|overseas, v1Available: bool }`。
3. **边界澄清**：本页的「市场」是**全局市场准入偏好**，与 §3.2「股票账户（券商开户实体）」是两个独立 bounded context——市场是市场，券商账户是券商账户，勿混。

## 6. 样式规范

1. **follow 当前项目 theme tokens**（`apps/mobile/src/theme/`：colors / spacing / typography）。图二仅作**行布局**参照，**不照搬其橙红色 label 配色**（per 项目设计资产复用原则）。
2. toggle ON 配色候选：项目 `colors.brand[500]`（蓝 `#2456E5`）或 `colors.accent`（橙 `#FF8C00`，恰接近图二）——**留 mockup / SDD plan 决策，PRD 不锁死**。
3. 项目尚无 Switch / Toggle 组件——SDD 阶段需新建（可基于 RN 原生 `Switch`）。占位 UI 阶段按 [sdd.md](../../conventions/sdd.md) 类 1 占位 4 边界：原生 RN `Switch` + `Text`，不抠像素。

---

## 7. 边界与非功能（Out of Scope / NFR）

1. **Out of Scope（V1 本页不做）**：
   - 海外市场真实数据接入（V2+）。
   - 市场端点初始化 / 熔断的网关层实现细节（本页只管开关偏好）。
   - 外币 → RMB 折算汇率源（属 Master §3.3 自选列表）。
2. **NFR**：
   - 置灰市场点击零副作用，不触发任何网络 / 初始化。
   - 偏好写入需稳定持久化（用户重进保持上次激活态）。

## 8. 决策记录与剩余延后

### 本轮已决

| 决策点          | 结论                                     |
| --------------- | ---------------------------------------- |
| toggle 保存方式 | 即时持久化（切换即落库，无保存按钮）     |
| 海外置灰副文案  | 固定「即将支持」                         |
| min-1 提示形态  | 行内轻提示 + 开关回弹；具体视觉留 mockup |

### 剩余延后（非本页范畴）

1. 激活态向下游的**传播机制**（领域事件广播 vs 下游读市场偏好表）→ 属 §3.1 网关架构，SDD / ADR 决。
2. A 股「含北交所」的范围在导入 / 搜索层如何体现 → 属导入 / 搜索 PRD（记录于 Master 倒查）。
