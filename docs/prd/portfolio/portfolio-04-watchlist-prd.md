## 1. 背景与定位

自选列表是 portfolio 的「资产总览与监控标的的**动态分流池**」（Master §3.3），借鉴同花顺自选范式。用户用**分组**组织关注标的，在分组 Tab 间横滑切换，长按单个标的做快捷操作。

- **系统分组**（自动生成，只能隐藏 / 拖拽，不可删改）：仅「自选」（默认落点）+「持仓」（份额 > 0 自动驱动）。
- **自定义分组**：用户自建，可删除 / 重命名 / 隐藏 / 拖拽排序。
- 市场（PRD01）/ 券商（PRD02）**不自动建组**——跨市场 / 跨账户的组合筛选属过滤器维度（V1 延后，见 §8）。

---

## 2. 用户故事（User Scenarios）

1. 用户在某分组 Tab 下浏览关注的股票，看 名称 / 最新价 / 涨幅 / 涨跌（涨红跌绿）。
2. 用户横滑切换分组 Tab。
3. 用户长按某股 → 弹出菜单：删除 / 固顶 / 移到最前 / 移到最后 / 分组·颜色 / 笔记。
4. 用户点 ☰ → 进入「全部分组」管理：新建分组、隐藏系统组、拖拽排序、删除 / 重命名自定义组。
5. 用户在全局搜索里搜到一只股票 → 加入某分组（新增自选）。
6. 用户在个股详情页 → 「调分组」加入自选。
7. 持仓组：份额 > 0 的标的自动出现，用户不可手动移出（依赖导入特性）。

---

## 3. 页面结构与交互

三屏：**主列表（图一）↔ 长按菜单（图二）↔ 分组管理（图三，由 ☰ 进入）**。

### 3.1 屏 1 — 自选主列表（图一）

1. **顶部分组 Tab**：横向可滑动，顺序 = 用户在分组管理里的拖拽序，隐藏的组不出现；末尾 **☰** → 进入屏 3。
2. **去掉** Tab 下方左侧两个图标（编辑 + 排序 / 筛选）——入口暂不做。
3. **列头**：名称 ｜ 最新 ｜ 涨幅 ｜ 涨跌。
4. **每行**：股票名 + 代码（板块标签 融 / 创 / 科创**去掉**）；最新 / 涨幅 / 涨跌三列数值**涨红跌绿**。
5. **长按某行** → 弹出屏 2 菜单。
6. 行情数值由 quote-provider 提供，本页只渲染（本 PRD 不含拉取，见 §8）。

### 3.2 屏 2 — 长按快捷菜单（图二）

长按股票行弹出，6 项：

| 操作      | 说明                                                        |
| --------- | ----------------------------------------------------------- |
| 删除      | 从当前分组移除该标的（持仓组受限，见下）                    |
| 固顶      | 常驻置顶（重排后仍固定在分组最顶部）                        |
| 移到最前  | 一次性移到列表前部（位于固顶项下方）                        |
| 移到最后  | 移到分组列表尾部                                            |
| 分组·颜色 | 改归属分组 + 打颜色标记                                     |
| 笔记      | 进入 §3.6 笔记（同一功能，不同入口；与「分组·颜色」同逻辑） |

- **去掉「批量操作」**。
- **排序优先级**：固顶项常驻分组最顶；「移到最前 / 最后」只在**非固顶区**内调位，故移到最前的项位于固顶项下方。
- **持仓组**内标的：份额 > 0 由事实驱动，**不可手动删除 / 移出**（per Master §3.3）；「删除」项灰显禁用，其余操作（固顶 / 颜色 / 笔记）可用。
- **多入口同一操作**：「分组·颜色」与「笔记」和长按菜单只是同一组操作的不同入口——个股详情页底栏（Master §3.4）同样展现这组操作按钮（调分组 / 写笔记 / 预警等）。长按菜单 ≈ 详情页底栏。

### 3.3 屏 3 — 全部分组管理（图三）

1. **标题**「全部分组」+ 右上「新建分组」。
2. **每组行**：组名 + 标的数量 + 👁（隐藏 / 显示切换）+ ☰（拖拽排序手柄）。
3. **系统组**（自选 / 持仓）：**只能隐藏 + 拖拽排序**，不可删除 / 重命名。
4. **自定义组**：隐藏 + 删除 + 重命名（⋯ 菜单）+ 拖拽排序。
5. 拖拽排序结果决定屏 1 的 Tab 顺序；隐藏的组不在 Tab 出现。

| #    | 需求                                                                                 |

## 5. 数据模型（PRD 级，非最终 schema）

### 5.1 分组（Group）

`{ id, userId, name, type: system | custom, systemKind: watchlist | holdings | null, visible: bool, order: int }`

- 系统组：`type=system`，`systemKind ∈ {watchlist, holdings}`，随账号自动存在，不可删 / 改名。
- 自定义组：`type=custom`，全 CRUD。

### 5.2 自选标的（WatchlistItem）

`{ id, groupId, market, code, pinned: bool, order: int, color, noteRef }`

- 业务主键 = `market + code`（per Master §4.1）；`market` 用 015 `Instrument.market` 词表 `cn`/`hk`/`us`（与 01 `market_preference.market` 对齐到同一词表，不做映射）。
- `持仓` 组的成员**派生自持仓事实**（份额 > 0），非用户手动维护的 WatchlistItem（实现可为只读视图）。

### 5.3 边界澄清

- 行情快照（最新 / 涨幅 / 涨跌）**不落本表**——属内存实时计算 / quote-provider（Master §4.1 动静分离）。
- 市场 / 券商不作为分组实体；跨市场 / 跨账户筛选是过滤维度（V1 延后）。

## 6. 关键产品决策

| 决策点                 | 结论                                                 | 理由                                                      |
| ---------------------- | ---------------------------------------------------- | --------------------------------------------------------- |
| 系统分组来源           | 仅「自选」（默认）+「持仓」                          | 保持简单；市场 / 券商不自动建组，跨维筛选走过滤器（延后） |
| 添加自选入口           | 全局搜索 + 详情页调分组（双入口）                    | 覆盖主动搜索与浏览中加入两场景                            |
| 涨跌配色               | 涨红跌绿（A 股惯例）                                 | 国内用户习惯；新增 quote-up/down token，不复用 err/ok     |
| 实时行情范围           | 本 PRD 不含拉取，provider 作依赖                     | quote infra（Master §4.4/4.5）单独，本页只消费            |
| 长按菜单               | 删除 / 固顶 / 移到最前 / 移到最后 / 分组·颜色 / 笔记 | 去掉批量操作                                              |
| Tab 下两图标           | 去掉                                                 | 编辑 / 排序 / 筛选入口暂不做                              |
| 列表明暗主题           | 一律项目浅色 theme（不引入深色）                     | 全模块视觉统一                                            |
| 板块标签（融/创/科创） | 去掉                                                 | 归属工具不交易，板块标签暂无用                            |
| 笔记归属               | = §3.6 笔记（同一功能，不同入口）                    | 与「分组·颜色」同逻辑，多入口共享                         |
| 操作按钮入口           | 长按菜单 + 详情页底栏（双入口）                      | Master §3.4 详情底栏同展现这组操作                        |
| 添加自选默认分组       | 默认落「自选」组                                     | 最省事；事后可调分组                                      |
| 排序优先级             | 固顶区常驻置顶 > 非固顶区（移到最前/最后在区内调位） | 符合同花顺语义                                            |

## 7. 样式规范

1. **涨跌专用 token**：新增 `quote.up`（红）/ `quote.down`（绿）/ `quote.flat`（灰），**不复用** `err`（红）/ `ok`（绿）——语义相反，避免混淆。
2. **一律采用项目浅色 theme**（不引入深色）；三张同花顺截图仅作**布局参照**，配色 / 明暗全部按项目 token，不照搬。
3. 项目现有 UI 组件（`apps/mobile/src/ui/`）无 Tab 栏 / 长列表 / 长按菜单 / 拖拽排序组件——SDD 阶段需新建（拖拽 / 长按可基于 RN 手势库）。

---

## 8. 边界与非功能 + 剩余延后

### Out of Scope（V1 本特性不做）

1. **实时行情拉取 / 降级**（quote-provider，Master §4.4/4.5）——单独 infra / PRD，本页只消费。
2. **持仓数据来源**（导入特性）——持仓组依赖它，未建则该组为空。
3. **跨市场 / 跨账户过滤器**（图一被去掉的两图标对应能力）——V1 延后。
4. **外汇折算 RMB**（Master §3.3）——依赖 FX 牌价，延后。
5. **追踪池 / 策略池**（Master §3.3 / §3.7）——V2。
6. **个股详情 / K 线**（长按外的下钻）——属详情 PRD。

### NFR

1. 分组顺序 / 可见性 / 自选项排序需稳定持久化。
2. 行情渲染走内存实时，列表滚动需流畅（大量标的时虚拟化）。

### 剩余延后（待 mockup / SDD）

1. **「颜色」标记调色板**：提供几种颜色 / 用在行底色还是色点 → 待 design 提示词 + mockup。
