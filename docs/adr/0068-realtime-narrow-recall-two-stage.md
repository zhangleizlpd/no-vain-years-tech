# ADR-0068: 实时窄召回两段式与选档理论 — 窗即召回、凸包清链、φ+形状行军

- Status: Accepted (2026-08-29)
- Deciders: @zhangleizlpd
- Tags: optionsdesk / retrieval / ranking / realtime / architecture
- Relates: [ADR-0064](0064-optionsdesk-retrieval-layering.md)（五层分层；本 ADR 对其作 §7 的逐条修订）· [ADR-0062](0062-optionsdesk-bounded-context.md) · [ADR-0043](0043-server-flat-module-paradigm.md)（判据落纯函数 `*.rules.ts`）· [ADR-0067](0067-vendor-absence-semantics.md)（缺失语义，本 ADR 的报价护栏与其同族）

## Context

064 落地的实时读路径是「**离线档 + 报价覆盖**」：库内收盘快照当基线，vendor 实时值按矩形窗（`0.7–1.05 × spot`）尾部覆盖。一天的设计对焦（2026-08-29，全部结论经双日回放 + 全量仿真验证）确认该范式与实时档的定位冲突，且携带四个结构缺口（窗绊线单向 / `window_over_cap` 余量仅 4.5% / 混合口径 / 未支持市场 throw→read_failed）。同时，「同 K 不同 DTE 选哪条腿」此前无显式判据 —— 排序器（`layeredRanker`）回答的是「腿之间怎么排」，不回答「该锁多长的期限」。

⇒ 本 ADR 定两件事：**实时召回的新形态**（两段式）与**选档的完整理论**（清链 + 行军），并逐条修订 ADR-0064。

## 决策 1 · 两档定位二分 —— 实时档废弃「离线 + 覆盖」范式

|          | 离线档（收盘档）              | 实时档                                                |
| -------- | ----------------------------- | ----------------------------------------------------- |
| 视野     | 宽 —— 全量防盲点、找新想法    | **窄** —— 只看已定规则内的少量腿                      |
| 召回方向 | 宽 → 收（全链进内存，条件砍） | **窄 → 取**（规则先定 code，再问 vendor）             |
| 数据     | 本地 DB 全量                  | vendor 实时报价；DB 只出**骨架**（K/到期日/周期）+ OI |

🚨 **护栏：窗永不进离线档。** 离线档的价值主张是宽视野；把窄召回的窗搬进去等于拆掉「全腿视角」与「多看产生想法」。离线档可复用的是特征层与选档层（纯函数、口径无关，且全部标定本就在收盘数据上做的），不是召回窗。

> ✅ **自 070（2026-08-31）起本护栏是机器强制的，不再只是文字**（sunset trigger #6 的裁决）：
>
> 1. **结构闸** —— `scripts/checks/check-optionsdesk-rule-constants.ts` 不变量 **#11**：`leg-fwd-chain.rules.ts` / `leg-march.rules.ts` 的去注释源码里出现**任何** `leg-window` 模块引用即红（比 import 行扫描更严：静态 / re-export / 动态 import 全拦），与既有不变量 #9「窗判据只住 `leg-window` / `leg-delta-surface`」合成「窗与 fwd 管道互不渗透」的完整表达。
> 2. **行为闸** —— 离线响应中审计 #12（带外横档）出现数为零、行级带内外标恒缺省、离线请求零 vendor 外呼（`optionsdesk-070.offline-ladder.it.spec.ts` ⑥⑦ 臂）。
>
> 📌 两闸方向相反才拦得住：结构闸钉「代码不许引」，行为闸钉「响应里不许长出窗的产物」——只有前者时，跨模块间接传导的窗语义仍可能溜进响应。

## 决策 2 · 两段式召回 —— K 级窗是实时召回的第一段

```text
第一段（选码）: 昨日 Δ 面查表 (sticky moneyness) → moneyness 包络 + pad → K-梯形窗
第二段（判腿）: 同一 recallCandidates 吃实时值（判据单点存活）
```

- **K-梯形窗**：K 级进窗判据 = 该 K 在意图 DTE 段内**任一**到期日预测落带（∩ 收租 W 帽 `K ≤ min(spot, W) × 1.03`）；进窗 K 取段内**全部**到期日 —— fwd 阶梯不能断链（实测逐到期日命中仅 65%）。腿级带内标用同批实时 Δ 打，带外横档保留供比价。
- **窗教义修订**：064 期 `leg-window.rules.ts` 立的「窗 MUST NOT 当 filter 删腿」在实时档**撤销** —— 窗就是召回第一段；该教义存续范围收窄为 bootstrap 宽窗（新锚无昨日 Δ 面时的一次矩形宽取）。`0.7 × spot` 下界同时撤销：新窗两条边都由 Δ 带包络给出（带的 Δ 下限本身就是「再深就没权利金」的判据）。
- **腿级判据单点不动**：第二段跑的是与离线**同一个** `recallCandidates` 入口，只是输入换成实时值。K 级前置门是新概念，腿级成员判定仍恰好一处。
- **spot 三级降级**：盘中基准新鲜（≤90s）→ 实时补一发 → 显式「实时不可用」。🚫 不新造 TTL 缓存（第二个会漂移的 spot 真相源），🚫 不拿昨收定窗。
- **未支持市场 guard**（PR #286 已先行）：闸判开之后、定窗之前判市场支持，不支持 ⇒ 零外呼整体回落收盘档并标 `source_unavailable`。🚨 guard 必须在闸**之后**（休市时段是正常收盘档，挪到闸前 = 永远为真的告警）。
- **每视角独立时刻 = by-design**：每视角一个 Δ 带一个窗一次外呼，三视角三个 `quoteAsOf`；跨视角一致性只判业务日。这是定位（每视角独立检索条件）的直接后果，不是缺陷 —— 记在此处防止半年后被当 bug 重查。

## 决策 3 · 清链管道归特征加工层 —— θ 无关的纯几何

取回后的候选集按 K 分组，每 K 依次：

1. **报价护栏**：`ask ≤ bid`（交叉/锁定）⇒ 报价异常剔候选并留痕。既有 `relativeSpread` 对交叉报价算出负值、`≤ 0.35` 闸照样放行 —— 这是实测过的真缺口。
2. **凸包剔劣档**（栈扫描）：`fwd(进X) < fwd(出X)` ⇒ 弹 X 级联再比，摊还 `O(n)`。**核心机器不变量：终态链 fwd 单调递减**（把 `while` 误写成 `if` 的实现在深级联输入上必红）。
3. **tick-分辨率共线合并**（零自由参数）：节点弦上垂距 `d < tick/(K−bid)` ⇒ 凸起可被一个最小报价单位翻转 = 低于报价分辨率 = 共线，除名节点并段（合并 fwd = 子段时间加权平均，无损）。ε 自适应方向正确：短档间自动宽（恰是 tick 噪声放大区），长档间自动窄。
4. **劣档三类标**，只标不删：凹陷支配 / 绝对支配（总权利金 ≤ 更短档 —— 业内视为日历套利违约，附「疑似陈旧报价」提示）/ 共线档。

📌 **合并的合法性判据就是共线本身**：子段 fwd 几乎相等 ⇒ 加权平均无损。非共线段禁止合并 —— 那是把贱卖段混进平均的**伪装混合**（`30d@20% + 150d@8%` 调和成 `180d@10%` 恰好过滤线的那种错，两处否决同源：见 §6 候选表「先过滤后凸包」）。

## 决策 4 · 精排层职责扩为「排序 + 选档」—— 分层判据 = θ 相关性

ADR-0064 给精排层的职责原文是「排序」。本 ADR 扩为「排序 + 选档」：φ+形状双条件行军产出每 K 的**推荐档**与**无合格档**两类判决。分层归属按 θ 相关性切：

| 产物                            | θ 相关？       | 归属层     |
| ------------------------------- | -------------- | ---------- |
| 凸包 / 劣档标 / 共线标 / fwd 链 | 无关（纯几何） | 特征加工层 |
| 推荐档 / 无合格档判决           | 相关           | **精排层** |
| 灰显、着色、折叠、文案          | —              | 表达层     |

🚫 **「先按 θ 过滤年化再跑凸包」已评估否决**：结论虽可证等价（年化 argmax 的斜率必在凸包上 ⇒ gate-fail ⟺ 过滤后为空），但 θ 掺入特征层意味着切档界须全量重算凸包/fwd（违 ADR-0064 不变量 ③），且屏上凭空少档、停点头上的 fwd 失去出处。

ADR-0064 不变量 ②（精排只读特征集）③（每特征恰好一处）逐条核对不破；粗排层仍 no-op 不动。

## 决策 5 · 选档理论 —— 倒序遍历与 φ+形状行军

**理论**：卖出长腿 = **倒序遍历 fwd 链**（静曲面下 DTE 收缩先吃最远段、最后吃最近段）。⇒ 胜者的严格定义：**整条前向路径上每一天都挣 ≥ φ 的最长档**。行军是该定义的构造性算法 —— 固收「骑收益率曲线选期限」（沿曲线延伸直到远期率跌破 hurdle）在期权卖方上的移植。

**行军判据**（作用在净链上）：

```text
延伸 = ①水平 fwd ≥ φ（φ = 档界旋钮，可配置）
     ∧ ②形状 每日衰减不回升（≤ β × 前段；前段衰减 ≤ 0 时退化为 γ 绝对帽）
停点 → ③可成交闸否决（收租 OI 口径；不过闸沿凸包退最近过闸档）→ ④档界终检
```

- **φ 是单旋钮**：语义 =「可持续再投资率」，取值 = **收租年化档界**。θ=自身年化模式（≡ 年化 argmax，恒等式 `年化₂ = [T₁·年化₁ + (T₂−T₁)·fwd]/T₂` 保证）保留为费率最大化备选。两模式各配三行预言机作性质测试。
  📝 **勘误（2026-08-30，069 specify 期）**：原文此处写「取值 = 意图档界（收租年化档 / 建仓周化档，两族口径不互比）」——撤销「建仓周化档」半句。行军/选档是**收租（长腿）机制**：本节理论通篇以「卖出长腿」与「收租 OI 口径」推导，实测裁决样本亦全为收租。建仓第一目标是接货（有效成本 `K − bid < spot` 判据、财报无标语义均以此立），期限选择由召回段 `[1,49]` + 周化排序承担（050/052）；对建仓套行军，曲线正常时退化为停链头（冗余），事件段曲线抬平时往远推档（与接货目标反向）。「两族口径不互比」（047 FR-018）仍然成立，只是它约束的是费率呈现与比较，不再暗示两族都跑行军。
- **形状条件的处置是「停」，不是「剔」**：一阶违规对象是**档**（剔正确），二阶违规对象是**段**（市场贱卖的远期时间）—— 截链尾即处置；中段剔除会制造伪装混合并抹掉推荐档本身。
- **θ 卡停点不卡行军起点**：短端 thin、中段合格的 K 梯会被卡起点误杀。
- **偏离业界 30–45 DTE 甜点是有据的**：那个甜点优化 theta/gamma（滚动收租、拒绝指派的玩家）；本系统锚定 W、接受指派（跌破 W 被指派是计划内建仓），目标函数是「边际时间费率 vs 再投资率」—— 目标函数不同，最优解自然不同（实测 fwd 最优档系统性落在 4–6 个月段）。
- **理论完整性**：行军管入场（静态路径每天 ≥ φ），φ-exit（剩余年化 < φ ⇒ 平仓滚新腿，future spec）管曲面动态偏离 —— 入出同一旋钮，合成完整的 carry + rolldown 优化。fwd 选腿对深实值退化**结构性免疫**（内在价值充水抬高链头年化、抬不动边际 fwd）—— ADR-0064 Context §2 的病灶在本机制下不复发。

**排除可解释**（ADR-0064 不变量 ④ 的升级）：从「每道门槛计数可见」升到「**逐档可解释**」—— 每 K 审计弹层，每行 = 原因类别 + 带数值的证据（「fwd 6.0% < φ 15%」而非「被排除」），去除原因 13 类四家族。

## 决策 6 · 财报语义 —— 瞄准不避开，三态标是常驻界面

本策略已为事件风险付过认知成本（V 是自做的基本面估值），财报段 IV 溢价是目标租金而非雷区。⇒ 财报标语义**中性偏机会**（禁劝阻式红标），落点在 **fwd 段**（事件落在 T₁→T₂ 之间 ⇒ 溢价灌在该段 fwd 里）。行军机制零改动 —— 财报段 fwd 天然高，机制自动伺服偏好。

三态标（有 / 无法确认 / 必跨-推断 gap>91 天）中「无法确认」是**常驻状态**而非兜底：取证（issue #287）确认 vendor 挂牌提前量 p50 = 14 天、提前挂牌率 ~20–25%，远月横档的财报可见性结构性缺失且不可修。增强方向 = 季度节奏推断（上次财报日 + 91k 天 ± 容差），随历史事件积累自我改善。

## 候选与否决

| 候选                                        | 否决理由                                                                                                        |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 继续「离线 + 报价覆盖」范式修补             | 与实时定位（窄→取）根本冲突；四缺口是范式性的                                                                   |
| BS 闭式解反推 K 区间                        | σ 是 (K,T) 的函数，不动点问题；查表（sticky moneyness）零公式且微笑已含在真实数据里                             |
| 新造 TTL spot 缓存                          | 第二个会漂移的 spot 真相源（违 ADR-0064 不变量 ③）；30s tick + 同批同刻复算已足                                 |
| fwd 只在月度档间算                          | 被凸包 + tick-共线取代 —— 按报价质量清链优于按周期血统排除（活价下周度好报价有资格赢）                          |
| 时间归一衰减判据（每日衰减/年化拖累作停走） | 与 owner 全部真实裁决**反序**（被拒的 140→293 归一后反比已接受的 49→112 平缓），实测证伪                        |
| 先按 θ 过滤年化再跑凸包                     | θ 掺入特征层 + 屏上缺档 + 伪装混合陷阱（§决策 4）                                                               |
| 二阶（形状）也做剔档再重连                  | 违规对象是段不是档；中段剔除 = 伪装混合，停即处置                                                               |
| SVI / 样条无套利平滑拟合                    | 定价工具非决策工具；可解释性不满足（「拟合曲线上的值」无法从屏幕反推），且抹平 bid 侧贱卖信号 —— 正是要抓的东西 |
| 每到期日限 N / 重排层                       | ADR-0064 决策 3 原判维持；选档不是多样性/商业化重排                                                             |

## 后果

- **正面**：四个结构缺口（绊线单向 / over_cap 余量 4.5% / 混合口径 / hk throw）全部结构性消灭；「同 K 选哪条腿」首次有显式、可测、可解释的判据；窗成本降一个量级（矩形 max 381 → 梯形实测 max 180，pad 后 ≤ 180）；离线档可白捡特征层与选档层（标定本就在收盘数据上做的）。
- **负面**：读路径重建的一次性成本；标定参数增多（φ/β/γ/OI_MIN/pad —— 但全部带实测锚点，且 ε 零参数）；「无法确认」「规则内无腿」「整梯无可成交」三种诚实空态的呈现与预期管理成为硬工作。
- **中性**：`layeredRanker` 与离线档读路径原样保留；~~两档并存两种呈现范式直到 P4~~ ✅ **P4 已 ship（070，2026-08-31）：收租视角的两种呈现范式在 us 市场锚上收敛为一种**——离线档收租接同一条清链/行军管道、同一份契约形状（`march` + 链级 `marchMode`），判据/参数/实现同源单点。仍并存的是：① **全腿 / 建仓视角**（蓄意零改动，宽视野价值主张不碰）；② **hk 锚收租**（069 四参数系 us 收盘分布标定，hk 接入待其自身标定片）；③ 召回层本身（离线宽 → 收 vs 实时窄 → 取，决策 1 的二分不变，本次收敛的是**选档与呈现**不是召回）。

## 实施载体

P1（W 轴统一，纯 server）→ P2（两段式召回重建，server+mobile）→ P3（清链 + 行军 + 审计弹层，server+mobile）→ P4（离线意图视角切换，**070 已 ship / 2026-08-31**，序列末片）。标定值与呈现规格归各 spec；本 ADR 只承载跨 spec 的结构决策。
