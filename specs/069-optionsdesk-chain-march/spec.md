# Feature Specification: 清链与行军选档 — 凸包净链、φ+形状行军、逐档可解释

**Feature Branch**: `069-optionsdesk-chain-march`
**Created**: 2026-08-30
**Status**: Clarified（2026-08-30；clarify 3 问已裁决回写）
**里程碑**: [ADR-0068](../../docs/adr/0068-realtime-narrow-recall-two-stage.md) 实施序列的 **P3 片**（server + mobile；P1 = 067 W 轴统一、P2 = 068 两段式窄召回均已 ship，P4 离线意图视角切换在后）

## 背景

068（#291）落地后，实时档候选 = 两段式窄召回产出的「规则内少量腿」。但「同 K 不同到期日选哪条腿」仍无显式判据——`layeredRanker` 回答的是「腿之间怎么排」，不回答「该锁多长的期限」。ADR-0068 决策 3/4/5 给出完整理论：先把每 K 的 fwd 链经纯几何清链管道洗成**净链**（报价护栏 / 凸包剔劣 / tick-共线合并 / 劣档三类标），再在净链上跑 **φ+形状双条件行军**产出每 K 的推荐档或无合格档判决，最后把「为什么不是这档」升级为**逐档可解释**的审计弹层（ADR-0064 不变量 ④ 的升级）。分层归属按 θ 相关性切：清链归特征加工层（纯几何），选档归精排层（θ 相关），呈现归表达层。**Scope = 收租视角**（行军是收租长腿机制，clarify Q4 裁决）：建仓视角本片零改动，唯一例外是报价护栏全域生效。

## Clarifications

## User Scenarios & Testing _(mandatory)_

### User Story 1 - 清链成净链：报价异常与劣档由几何判据处置 (Priority: P1)

用户在实时档看到的每 K fwd 链是**可信的净链**：交叉/锁定报价（ask ≤ bid）被剔出候选并留痕；被更短档支配的劣档经凸包弹出；低于报价分辨率的共线相邻档被无损合并；凹陷支配 / 绝对支配 / 共线三类劣档带标呈现而非消失。

**Why this priority**: 行军与审计都跑在净链上——清链是本片一切下游的输入。且它独立修复一个实测过的真缺口：既有 `relativeSpread` 对交叉报价算出负值、点差闸照样放行。

**Independent Test**: 构造含交叉报价 / 深级联劣档 / 共线节点的 K 梯输入，断言净链产物：剔除留痕、终态 fwd 单调递减、共线段合并值 = 子段时间加权平均、三类劣档标齐全。

**Acceptance Scenarios**:

1. **Given** 某 K 梯含一档 ask ≤ bid 的交叉报价，**When** 清链执行，**Then** 该档剔出候选、审计留痕为报价异常，且不再有负 `relativeSpread` 放行路径
2. **Given** 深级联劣档输入（弹出 X 后前档仍劣），**When** 凸包栈扫描执行，**Then** 级联弹出至终态链 fwd 单调递减
3. **Given** 相邻档对弦垂距 d < tick/(K−bid)，**When** 共线判定执行，**Then** 节点除名并段、合并 fwd = 子段时间加权平均；垂距不低于阈值的相邻段禁止合并
4. **Given** 总权利金 ≤ 更短档的长档，**When** 劣档标注执行，**Then** 标绝对支配并附「疑似陈旧报价」提示，档保留可见（只标不删）

---

### User Story 2 - 行军选档：每 K 直接给推荐档或无合格档 (Priority: P2)

用户在实时档收租视角每个 K 上直接看到系统推荐锁的期限档：行军沿净链倒序理论延伸（水平 fwd ≥ φ 且每日衰减不回升），停点过可成交闸与档界终检后成为推荐档；链头即不合格则诚实给出「无合格档」；整梯不过可成交闸给出「整梯无可成交」。

**Why this priority**: 这是本片的价值主体——「同 K 选哪条腿」首次有显式、可测、可解释的判据。依赖 US1 的净链作输入故列 P2。

**Independent Test**: 用已留痕的 owner 真实裁决样本回放：断言行军判决与裁决零反序；再以合成 K 梯覆盖延伸 / γ 帽退化 / 停点回退 / 空判决各分支。

**Acceptance Scenarios**:

1. **Given** 净链上存在连续若干档 fwd ≥ φ 且衰减形状合规，**When** 行军执行，**Then** 推荐档 = 满足「前向路径每天 ≥ φ」的最长档
2. **Given** 前段衰减 ≤ 0，**When** 形状条件求值，**Then** 退化为 γ 绝对帽继续判定，不因除零/负基准中断
3. **Given** 停点档 OI 低于 `OI_MIN`，**When** 可成交闸执行，**Then** 沿凸包回退至最近过闸档；全梯无过闸档则判整梯无可成交
4. **Given** 链头首档 fwd < φ，**When** 行军起步，**Then** 判无合格档；行军起点不设可成交闸（短端 thin、中段合格的 K 梯不被误杀）
5. **Given** 净链全程每档合格直至链尾，**When** 行军执行，**Then** 推荐链尾档（胜者定义的边界分支）
6. **Given** 切换 θ=自身年化模式，**When** 选档执行，**Then** 判决与年化 argmax 一致（恒等式性质）

---

### User Story 3 - 审计弹层：每一档为什么不被推荐，逐档数值证据 (Priority: P3)

用户在收租视角对任一 K 打开审计弹层，逐档看到它的处置与原因：每行 = 原因类别 + 带数值的证据（「fwd 6.0% < φ 15%」而非「被排除」），原因类别覆盖清链、行军、可成交、呈现四个家族；推荐档与两类诚实空态（无合格档 / 整梯无可成交）有明确呈现形态与预期管理文案。

**Why this priority**: 排除可解释是 ADR-0064 不变量 ④ 的升级（门槛计数 → 逐档可解释），是信任判决的前提；但它消费 US1/US2 的全部留痕，故最后接线。

**Independent Test**: 对一批真实锚的实时响应，断言每个非推荐档在弹层中恰有一条原因、类别在清单内、证据含数值；空态场景断言呈现为诚实空态而非错误。

**Acceptance Scenarios**:

1. **Given** 某 K 有档被凸包弹出，**When** 打开该 K 审计弹层，**Then** 该档一行显示劣档类别与其 fwd 对比数值证据
2. **Given** 某 K 判无合格档，**When** 打开审计弹层，**Then** 逐档给出停止原因（如首档 fwd 与 φ 的数值对比），页面呈现诚实空态而非错误
3. **Given** 某 K 有推荐档，**When** 查看实时档列表，**Then** 推荐档带推荐标识，被标劣档灰显/着色但可见

---

### Edge Cases

- K 梯清链后只剩单档：凸包与共线无操作，行军对单档直接判 φ 与停点闸
- 全梯报价均交叉被护栏剔空（净链为空）：判「整梯无可成交」，审计弹层逐档标 #1 报价异常（与 OI 不过闸成因由弹层区分，判决枚举不扩张）
- 停点回退路径穿过已合并的共线段：合并段作为单节点参与凸包回退
- 连续 ≥ 3 节点共线：跨段合并的加权平均与除名次序不影响终值（合并次序无关性）
- 周度与月度到期日混链：清链按报价质量处置，活价下周度好报价有资格赢（不按周期血统排除）
- 财报事件落在 T₁→T₂ 段内：该段 fwd 天然高，行军自动伺服，零特判、禁劝阻式红标
- tick 分辨率未知或非常数（不同价位区间 tick 不同）时共线阈值的取法
- 建仓视角边界：行军 / 清链（报价护栏除外）/ 审计弹层均不出现；建仓既有带内推荐标与本片收租推荐章两套语义不并存于同一行

## Requirements _(mandatory)_

### Functional Requirements

**清链管道（特征加工层，纯几何、θ 无关）**

- **FR-001**: 系统 MUST 在候选进入 fwd 链前执行报价护栏：ask ≤ bid（交叉/锁定）⇒ 剔出候选并留痕为审计条目；本护栏 MUST 先于点差闸，闭合 `relativeSpread` 负值放行缺口；本护栏为意图无关的数据质量闸，MUST 对全部视角候选生效（收租 scope 的唯一例外，clarify Q4）
- **FR-002**: 系统 MUST 在收租视角按 K 分组对 fwd 链跑凸包栈扫描剔劣档：`fwd(进X) < fwd(出X)` ⇒ 弹出 X 级联再比；终态链 MUST 满足 fwd 单调递减（核心机器不变量，深级联输入下以性质测试锁死）
- **FR-003**: 系统 MUST 执行 tick-分辨率共线合并：节点对弦垂距 d < tick/(K−bid) ⇒ 判共线、除名节点并段，合并 fwd = 子段时间加权平均；非共线段 MUST NOT 合并（伪装混合否决）；判据 MUST 零自由参数
- **FR-004**: 系统 MUST 对劣档打三类标且只标不删：凹陷支配 / 绝对支配（总权利金 ≤ 更短档，附「疑似陈旧报价」提示）/ 共线档
- **FR-005**: 清链管道 MUST 为纯函数、不读 θ / 意图 / 档界（θ 无关性）；判据落 `*.rules.ts` 纯函数（per ADR-0043），对候选来源无感（两段式窄召回与 bootstrap 宽窗产物均可作输入）

**行军选档（精排层，θ 相关）**

- **FR-006**: 系统 MUST 在收租视角净链上执行 φ+形状双条件行军：延伸 = 水平 fwd ≥ φ ∧ 每日衰减不回升（≤ β × 前段；前段衰减 ≤ 0 时退化为 γ 绝对帽）
- **FR-007**: 延伸条件违规的处置 MUST 是「停」（截链尾），MUST NOT 中段剔除后重连（防伪装混合）
- **FR-008**: 停点后 MUST 依次过可成交闸（收租 OI 口径 `OI_MIN`；不过闸沿凸包回退最近过闸档）与档界终检；行军起点 MUST NOT 设可成交闸
- **FR-009**: 系统 MUST 对每 K 产出三类判决之一：推荐档 / 无合格档 / 整梯无可成交；推荐档语义 = 前向路径每天挣 ≥ φ 的最长档；净链为空（候选全被清链剔除）MUST 判整梯无可成交，成因由审计条目区分
- **FR-010**: φ MUST 是单旋钮、取值 = 收租年化档界（行军 = 收租长腿机制，MUST NOT 应用于建仓——clarify Q4 / ADR-0068 勘误）；φ / β / γ / `OI_MIN` MUST 可配置且带实测标定锚点
- **FR-011**: 系统 MUST 保留 θ=自身年化模式为费率最大化备选（判决 ≡ 年化 argmax），入口为 server 配置项 only、UI MUST NOT 暴露切换（默认 φ=意图档界，切换呈现归 P4）；两模式 MUST 各配三行预言机性质测试
- **FR-012**: 财报段 MUST 零特判：段内事件溢价灌在 fwd 里由行军自动伺服；MUST NOT 出现劝阻式红标
- **FR-013**: 分层归属 MUST 按 θ 相关性：凸包 / 劣档标 / 共线标 / fwd 链归特征加工层，推荐档 / 无合格档判决归精排层，灰显 / 着色 / 折叠 / 文案归表达层；ADR-0064 不变量 ②（精排只读特征集）③（每特征恰好一处）MUST 核对不破

**审计与呈现（表达层）**

- **FR-014**: 系统 MUST 在收租视角提供每 K 审计弹层：逐档一行 = 原因类别 + 带数值证据；每个被剔 / 被标 / 未推荐档 MUST 恰有一条原因条目，MUST NOT 存在无原因排除
- **FR-015**: 去除原因分类 MUST 覆盖以下 13 类四家族（2026-08-30 clarify 定稿），类别集合前后端 MUST 严格一致：

  | #   | 家族            | 类别                                          | 数值证据示例                  |
  | --- | --------------- | --------------------------------------------- | ----------------------------- |
  | 1   | A 清链          | 报价异常（ask ≤ bid 交叉/锁定，剔候选）       | `bid 0.52 / ask 0.48`         |
  | 2   | A 清链          | 凹陷支配（凸包弹出）                          | `fwd(进) 4.1% < fwd(出) 6.3%` |
  | 3   | A 清链          | 绝对支配（总权利金 ≤ 更短档，疑似陈旧报价）   | `权利金 1.20 ≤ 短档 1.35`     |
  | 4   | A 清链          | 共线除名（并入合并段）                        | `垂距 0.3 tick < 1 tick`      |
  | 5   | B 行军          | 水平违规：fwd < φ（含链头即违规 → 无合格档）  | `fwd 6.0% < φ 15%`            |
  | 6   | B 行军          | 形状违规：每日衰减回升超 β × 前段             | `衰减 0.9 > β·前段 0.6`       |
  | 7   | B 行军          | 形状违规：γ 绝对帽（前段衰减 ≤ 0 的退化分支） | `衰减 0.8 > γ 0.5`            |
  | 8   | B 行军          | 档界终检未过                                  | `年化 14.2% < 档界 15%`       |
  | 9   | B 行军          | 合格非停点（在推荐路径内，被更长档胜出）      | `合格，推荐档 DTE 152 更长`   |
  | 10  | C 可成交        | 停点 OI 不过闸（沿凸包回退弃档）              | `OI 3 < OI_MIN 50`            |
  | 11  | C 可成交        | 整梯无过闸（全梯弃 → 整梯无可成交）           | `max OI 8 < OI_MIN 50`        |
  | 12  | D 呈现/召回边界 | 带外横档（预测带外保留比价，非候选）          | `Δ 0.08 < 带下限 0.15`        |
  | 13  | D 呈现/召回边界 | 报价缺失 / fwd 不可算（缺 bid 或缺相邻基准）  | `bid 缺失`                    |

- **FR-016**: 推荐档 MUST 带推荐标识；劣档灰显 / 着色但保持可见；无合格档与整梯无可成交 MUST 呈现为诚实空态（非错误），带预期管理文案

**边界与回归**

- **FR-017**: 离线档读路径 MUST 本片零改动；清链与行军仅接线实时档（标定用收盘数据离线跑，不动线上离线读路径）
- **FR-018**: 既有 `layeredRanker` 排序职责 MUST 原样保留；选档为精排层新增产物，不改既有排序语义
- **FR-019**: 建仓视角 MUST 本片零改动：不跑清链（报价护栏除外）、不跑行军、无推荐档判决、无审计弹层入口；既有带内推荐标（`|Δ| ∈ [0.40, 0.55]`）与周化排序原样保留

### Key Entities

- **fwd 链**: 同 K 按到期日升序的边际远期费率序列，清链管道的输入
- **净链**: 清链产物——护栏剔除、凸包弹出、共线合并后 fwd 单调递减的链，行军的唯一输入
- **劣档标**: 凹陷支配 / 绝对支配 / 共线三类，只标不删，携带判定数值
- **行军判决**: 每 K 三态之一（推荐档 / 无合格档 / 整梯无可成交），含停点原因
- **审计条目**: 逐档的原因类别 + 数值证据，13 类四家族，服务弹层呈现
- **行军参数集**: φ（意图档界）/ β（衰减比例帽）/ γ（绝对帽）/ `OI_MIN`（可成交闸），全部可配置、带实测锚点

## Success Criteria _(mandatory)_

### Measurable Outcomes

- **SC-001**: 在已留痕的 owner 真实裁决样本上，行军判决与人工裁决**零反序**（不存在「人接受的档比人拒绝的档在判决中更劣」的样本对）
- **SC-002**: 收盘全量真实链仿真中，清链终态 fwd 单调递减不变量**零违例**；共线合并前后行军判决**不变**（无损性）
- **SC-003**: 实时响应中每个非推荐档在审计弹层恰有一条原因、类别在 13 类清单内、证据含数值；抽样核对**零**「无原因排除」
- **SC-004**: 交叉报价（ask ≤ bid）候选放行数为**零**（既有负 `relativeSpread` 缺口闭合的直接判据）
- **SC-005**: 用户在实时档看到推荐标与打开审计弹层无额外等待（清链与行军在同一次请求内完成，响应时间无量级变化）
- **SC-006**: 离线档（收盘档）读路径重建前后全量请求逐值对比**零差异**
- **SC-007**: φ / β / γ / `OI_MIN` 四参数标定完成并带实测锚点留档本 spec（含标定数据面与判据）
