# Feature Specification: 离线档收租阶梯 — 意图视角切 fwd 阶梯呈现、计划/执行同口径

**Feature Branch**: `070-optionsdesk-offline-ladder`
**Created**: 2026-08-30
**Status**: Clarified（2026-08-30；specify 期 2 项 + clarify 期 2 项裁决已回写）
**里程碑**: [ADR-0068](../../docs/adr/0068-realtime-narrow-recall-two-stage.md) 实施序列的 **P4 片**（末片；P1 = 067 W 轴统一、P2 = 068 两段式窄召回、P3 = 069 清链与行军均已 ship）

## 背景

069（#293/#294）落地后，「同 K 锁多长期限」的完整判据（清链净链 + φ+形状行军 + 推荐章 + 逐档审计弹层）只存在**实时档**；离线档（收盘档）收租视角仍是平铺腿表 + `layeredRanker` 排序。owner 的工作流是晚上在离线档宽视野做计划、盘中在实时档执行——两档两套呈现范式意味着**计划与执行不同口径**：晚上看不到行军推荐，盘中的推荐无法与昨晚的计划对表。

08-29 设计对焦 §5d 已裁决复用边界：**召回窗 ❌ 绝不复用**（离线守宽视野，定位相反）；特征层（凸包/tick-共线/fwd）与选档层（行军）✅ **白捡**——纯函数、口径无关，且 069 全部标定本就在收盘数据上做，离线档才是其原生环境；OI 盘中冻结 ⇒ 可成交闸零差异。核心收益 = **计划/执行同口径**（与 067 统一 W 轴同一理由）。

本片同时收口三笔挂账：ADR-0068 sunset trigger 第 6 条（「窗不进离线」护栏是否机器强制——specify 期已裁决**机器双闸**）、069 FR-011 defer（θ=自身年化模式切换的呈现）、068 defer（离线档「规则内无腿」空态文案）。

## Clarifications

### Session 2026-08-30

- Q（specify 期）: 建仓视角在离线档如何处置（08-29 §5d「只给意图视角」复数表述 vs 069 clarify Q4「行军不适用建仓」）？ → A: **建仓零改动**。P4 实质 scope = 离线档**收租**视角；建仓期限选择由召回段 `[1,49]` + 周化排序 + 带内推荐标承担（050/052 已自洽），对建仓跑行军与接货目标反向（069 Q4 / ADR-0068 勘误同判）。建仓在两档的呈现天然一致（实时档建仓本就无阶梯）。
- Q（specify 期）: 「窗不进离线档」护栏（ADR-0068 决策 1，目前仅文字）是否升级为机器强制？ → A: **机器双闸**。①行为闸：离线档接入 fwd 管道前后候选成员集恒等的自动断言（护栏语义「fwd 管道只作用排序/呈现不动成员」的可执行化）；②结构闸：离线读路径禁引窗/两段式召回模块的依赖方向断言。P4 正是离线读路径首次接触 fwd 管道、定位侵蚀风险从假设变现实的时刻；文字护栏同时保留。裁决随本片回写 ADR-0068（sunset trigger 消费注记）。
- Q（clarify 期）: 港股锚在离线档是否接入行军阶梯？ → A: **本片排除**。hk 锚收租离线保持既有平铺；069 四参数系 us 收盘分布标定（`OI_MIN=50` / β=1.47），hk 期权 OI 结构性更薄、tick 规格表不同（共线判据依赖 tick），未标定参数下要么空态噪音要么失真推荐——失真推荐比无推荐更贵。管道 market 参数化留形状，hk 接入归 hk 标定后续片。
- Q（clarify 期）: 本片 UI 是否走 mockup-first？ → A: **免 mockup**（068 先例）。呈现组件零新增（推荐章/灰显微标/审计弹层均 069 已定型），离线差异为文案/标注级（口径标/时效/空态/模式标示）；UI 规格由 plan 的 UI 段承载，069 `design/` 基线作参照。

## User Scenarios & Testing _(mandatory)_

### User Story 1 - 晚间计划看到与盘中同口径的推荐（Priority: P1）

owner 晚间在离线档收租视角复盘持仓锚：每个 K 呈现净链 fwd 阶梯与三态判决（推荐档 / 无合格档 / 整梯无可成交），推荐章语义与盘中实时档完全同判据——晚上定的计划，盘中打开实时档能对上表。

**Why this priority**: 计划/执行同口径是 P4 的存在理由；没有它，行军判据只在盘中可见，离线档的「多看产生想法」与实时档的「规则内执行」之间断裂。

**Independent Test**: 对有收盘链的锚请求离线档收租视角，断言每 K 的判决与直调 069 管道（同一批纯函数、同一收盘数据）逐值一致；全腿/建仓 tab 原样。

**Acceptance Scenarios**:

1. **Given** 某 us 锚有收盘链且收租门槛后有候选，**When** 打开离线档收租视角，**Then** 每 K 呈现 fwd 阶梯语义与三态判决，推荐档带推荐章，判决与同数据直调管道一致
2. **Given** 069 标定数据面（同一收盘全量），**When** 离线档收租判决与 069 标定回放对比，**Then** 全部 K 梯逐值一致
3. **Given** 用户切到全腿 tab，**Then** flat 平铺原样、零阶梯元素；切到建仓 tab，**Then** 既有带内推荐标与周化排序原样

---

### User Story 2 - 离线档逐档可解释与口径诚实（Priority: P2）

owner 在离线档对任一 K 打开审计弹层，逐档看到「为什么不是这档」的原因与数值证据；所有数值明示昨收口径与数据基准日期，价差类信号以提示而非权威闸形态出现。

**Why this priority**: 没有可解释与口径标，离线推荐是一个无法核对、且可能被误当实时的黑箱数字；但它消费 US1 的判决产物，故次序在后。

**Independent Test**: 对离线响应断言每个非推荐档在弹层恰有一条原因、类别在 069 的 13 类清单内、证据含数值；抽样断言所有数值呈现均可追溯昨收基准日期。

**Acceptance Scenarios**:

1. **Given** 某 K 有被标/被停/未推荐档，**When** 打开离线档审计弹层，**Then** 逐档一行 = 原因类别 + 带数值证据，类别在 069 FR-015 的 13 类内
2. **Given** 离线档任一 fwd/推荐/审计数值，**Then** 呈现带「基于 MM-DD 收盘」时效口径标
3. **Given** 昨收数据中某档 ask ≤ bid（交叉报价），**Then** 该档在表中保持可见、带报价异常标 + 昨收口径提示，净链将其除名且审计留痕——不从呈现中消失

---

### User Story 3 - 诚实空态与模式标示（Priority: P3）

收租门槛后零候选时离线档显式呈现「规则内无腿」空态而非空白或错误；server 配置切到 θ=自身年化模式时阶梯被动标示当前模式，UI 始终不提供切换入口。

**Why this priority**: 两笔 defer 挂账（068 空态 / 069 θ 呈现）的收口；不影响主链路可用性。

**Independent Test**: 构造门槛后零候选场景断言空态文案；翻转 server 模式配置断言标示出现且无 UI 切换控件。

**Acceptance Scenarios**:

1. **Given** 某锚收租门槛后零候选，**When** 打开离线档收租视角，**Then** 显式「规则内无腿」诚实空态（非错误），带昨收口径标注
2. **Given** server 配置 θ=自身年化模式，**When** 查看阶梯，**Then** 呈现被动标示当前模式（推荐语义 = 年化 argmax），且无任何 UI 切换入口
3. **Given** 默认 φ=意图档界配置，**Then** 无模式标示噪音（默认态不打扰）

---

### Edge Cases

- 港股锚的离线收盘链：本片排除阶梯语义（clarify 裁决），hk 收租离线保持既有平铺与既有响应（golden 判据并入 FR-012）；hk 接入归 hk 标定后续片
- 某 K 缺相邻到期日基准或缺 bid ⇒ fwd 不可算：审计 #13，继承 069 分类零新增
- 全梯报价异常（净链为空）：判整梯无可成交；呈现成员仍全部可见（只标不剔），审计逐档 #1
- 非交易日/盘中打开离线档：数据基准 = 最近交易日收盘并明示日期；MUST NOT 混入实时值（混合口径正是 064→068 消灭的病灶）
- 单档 K 梯、共线并段、停点段内回退：继承 069 行为，离线档零新分支
- 锚无收盘链/新锚无快照：既有离线空态原样，不新造
- 财报事件落在 fwd 段内：零特判自动伺服，禁劝阻式红标（继承 069）

## Requirements _(mandatory)_

### Functional Requirements

**呈现范式切换（表达层）**

- **FR-001**: 离线档收租视角（us 市场锚）MUST 接入与实时档同一套 fwd 阶梯呈现语义——腿表结构保留：行内推荐章 + 每 K 三态判决（推荐档 / 无合格档 / 整梯无可成交）+ 劣档灰显/着色微标 + 轻点开审计弹层；全腿视角 MUST 保持 flat 平铺零改动；建仓视角 MUST 零改动（specify 期裁决）；hk 锚收租离线 MUST 保持既有平铺（clarify 裁决，hk 标定后续片）
- **FR-002**: 离线阶梯与实时阶梯 MUST 复用同一呈现契约形状与组件语义（同源单点），允许的差异仅限：昨收口径标 + 时效文案 + 降级项；MUST NOT fork 出第二套阶梯语义
- **FR-003**: 离线档 MUST 全程带昨收口径标识：数据基准 = 最近交易日收盘，fwd/推荐/审计数值 MUST 可追溯该基准日期，呈现 MUST 含时效文案
- **FR-004**: 价差类信号在离线档 MUST 降级为「昨收口径提示」：报价质量类标注（报价异常/疑似陈旧）保留但附昨收口径提示，MUST NOT 以权威闸形态呈现

**管道接入（特征加工层 + 精排层）**

- **FR-005**: 清链（报价护栏/凸包/tick-共线/劣档三类标）、行军（φ+形状/停点闸/档界终检）与审计装配 MUST 复用 069 同一份实现（每判据恰好一处，ADR-0064 不变量 ③）；离线接入 MUST NOT fork 第二份判据
- **FR-006**: 成员不变（护栏行为闸）：离线档接入 fwd 管道前后，收租视角候选成员集 MUST 恒等——清链的「剔」在离线档 MUST 降为「标」（报价异常档保持可见、净链除名、审计留痕）；fwd 管道 MUST 只作用标注/排序/选档/呈现
- **FR-007**: 窗不进离线（机器双闸，specify 期裁决）：①行为闸 = FR-006 成员恒等的自动断言；②结构闸 = 离线读路径 MUST NOT 引用 K-窗/两段式召回模块（依赖方向机器断言），且离线响应 MUST NOT 出现带内外标或审计 #12（带外横档）类别；ADR-0068 决策 1 文字护栏同时保留，本裁决 MUST 回写 ADR-0068（sunset trigger 第 6 条消费注记）
- **FR-008**: 行军参数 φ/β/γ/`OI_MIN` MUST 沿用 069 标定值与同一配置单点，MUST NOT 为离线档另设第二套参数；离线可成交闸取昨结 OI（盘中冻结 ⇒ 与实时同值）

**挂账收口（表达层）**

- **FR-009**: θ=自身年化模式呈现（069 FR-011 defer 收口）：入口维持 server 配置项 only、UI MUST NOT 暴露切换；配置为 θ 模式时阶梯 MUST 被动标示当前模式（判决 ≡ 年化 argmax），离线与实时同一标示，MUST NOT 静默混用两模式语义；默认 φ 模式 MUST 无标示噪音
- **FR-010**: 「规则内无腿」空态（068 defer 收口）：离线档收租门槛后零候选 MUST 呈现诚实空态文案（非错误），语义与实时档空态对齐、口径标注昨收

**审计（表达层）**

- **FR-011**: 离线档收租视角 MUST 提供每 K 审计弹层：逐档一行 = 原因类别 + 带数值证据，13 类四家族枚举与 069 FR-015 严格同一份（前后端一致）；每个被剔/被标/未推荐档 MUST 恰有一条原因条目，MUST NOT 存在无原因排除；#12 在离线档结构性不产生（零窗），出现即 FR-007 结构闸红

**边界与回归**

- **FR-012**: 全腿视角、建仓视角的离线读路径与呈现、及 hk 锚收租离线响应 MUST 零改动（golden 判据）；实时档三视角 MUST 零既有行为改动（默认 φ 配置下逐字节不变；唯一允许新增 = FR-009 的 θ 模式条件标示，默认态不出现）
- **FR-013**: 既有 `layeredRanker` 排序职责 MUST 原样保留（069 FR-018 延续）；选档为离线响应新增产物，不改既有排序语义

### Key Entities

- **离线阶梯**: 离线档收租视角的每 K 净链 fwd 阶梯 + 三态判决 + 推荐章，与实时阶梯同契约形状，仅口径标不同
- **昨收口径标**: 数据基准（最近交易日收盘日期）+ 时效文案，离线档全部数值呈现的溯源标识
- **成员恒等断言**: 接入前后收租候选成员集的自动对比，护栏行为闸的载体
- **模式标示**: φ=意图档界（默认，无标示）/ θ=自身年化（被动标示）两态，随 server 配置呈现
- **净链 / 行军判决 / 审计条目 / 行军参数集**: 继承 069 定义，本片零扩展

## Success Criteria _(mandatory)_

### Measurable Outcomes

- **SC-001**: 同一收盘数据面上，离线档收租判决与 069 标定回放**逐值一致**（全部 K 梯零分歧——管道同源单点的行为判据）
- **SC-002**: 离线档接入前后收租候选成员集全量回放**恒等**（行为闸绿）；全腿/建仓离线响应与 hk 锚收租离线响应 golden **逐字符零差异**；实时档三视角默认配置下响应零改动
- **SC-003**: 结构闸绿：离线读路径对窗/两段式召回模块**零依赖**（机器断言常驻）；离线响应中带内外标与审计 #12 出现数为**零**
- **SC-004**: 离线档每个非推荐档在审计弹层恰有一条原因、类别在 13 类清单内、证据含数值；抽样核对**零**「无原因排除」（069 SC-003 的离线镜像）
- **SC-005**: 口径与空态诚实：离线档数值呈现 100% 可追溯昨收基准日期；「规则内无腿」场景呈现显式空态而非空白或错误；θ 模式翻转时标示与判决语义同步切换
