## 加了 X → 动哪个 workflow

1. **server runtime env var**（DB/LLM/SMS/OSS…）→ **不进 workflow**，走 `config-env-sync` 的 9 连 boot-path（尤其 compose 映射 + `deploy.yml` 那次确保 prod 有值）。
2. **新 GitHub secret** → 上表对消费 job：ACR(`_USERNAME`/`_PASSWORD`/**`_REGISTRY`**)=`build-image`+`deploy` 双发；Cloudflare(`_API_TOKEN`/**`_ACCOUNT_ID`**)=`deploy-web`；Expo=三个 mobile release；SSH(`APP_SSH_KEY`/`APP_HOST`/`APP_SSH_USER`)=`deploy`+**`deploy-futu-shim`** 双发。
   > 🚨 **含标识符的值（镜像仓实例 ID / CDN 账号 ID / 主机地址）一律走 secret，不写进 workflow 明文** —— per [`information-boundary.md`](../../docs/conventions/information-boundary.md)；`check-identifier-boundary.ts` 在 CI 无条件扫，写死了会当场红。
   > **密文（`secrets.enc.env`）不是 GitHub secret** —— 它常驻主机 `/etc/nvy/`，带外 scp 推送（[`secrets-sops.md`](../../ops/runbook/secrets-sops.md) §3.3）。
3. **前端 `EXPO_PUBLIC_*` build-time** → `deploy-web.yml` + 相关 EAS profile（`eas.json`）。
4. **加 required check / 改 workflow 名 / 收紧 ruleset** → 先读 `docs/conventions/github-ruleset.md`（`.claude/rules/github-ruleset-sync.md` 另有硬 invariant）。
5. **mobile 发版面向（内测 ↔ 公开）翻盘** → repo var `MOBILE_RELEASE_PHASE`，**仅管 APK**（web 已解耦，见下）。未设 / 非 `public` = dev 期：`mobile-v*` tag 自动出 **internal markets-ON** 包，公开 APK **skip**。上线日 `gh variable set MOBILE_RELEASE_PHASE --body public`（查 `gh variable list`）→ tag 改出公开 markets-OFF 包，internal skip。任何 phase 下 `workflow_dispatch` 手动触发都 bypass 该 gate。iOS sim auto-tag 已关，仅手动 dispatch。**web 例外（2026-06-22 决策）**：`deploy-web.yml` 不再受 `MOBILE_RELEASE_PHASE`——`app.shintongtech.com` 恒为 **markets-ON 自测面**，每个 `mobile-v*` tag 恒发；公开合规分发只走 **APP 商店面**（`release-android-apk.yml`），web 退出公开 markets-OFF 面。
6. **EAS 账号分工（2026-06-19 锚定）**：slot `b`=caishen-ai=**生产账号**，`release-android-apk.yml`（公开包）**钉死 slot b**（用 `EXPO_TOKEN_B`，build 前 patch app.json owner+projectId 到 b）—— 其 per-project keystore 即上架锁定签名，公开包**永不轮换**。slot `a`=xiaocaishen=**内测/日常 dev**，`release-android-internal.yml`（内测）默认 slot a，认 repo var `EAS_ACCOUNT`（`a` 默认 / `b`）可在内测链轮换分摊 free 额度（15 Android/月/账号；公开链不轮换）。main 的 app.json 停 slot a（dev 默认），CI 构建时按账号 patch（runner 临时）。本地手动出包对齐脚本 `scripts/eas/switch-account.sh`。**上线公开包前置**：加 secret `EXPO_TOKEN_B` + 账号 B 先用一次**交互式** `eas build` 生成生产 keystore（CI `--non-interactive` 不能新建 keystore）。**人面向操作 + 排障手册**：`ops/runbook/mobile-eas-release.md`（含「build 没显示=看错账号视图」「首次 B 出包要交互式生成 keystore」等坑 + 上架 keystore 硬约束）。
